# One Piece Takeover

**Skyrim** × One Piece · visual · idea by the team

Bring One Piece into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> Pirate-hat Skyrim: I turned Windhelm's docks into the Grand Line with straw hats, Wanted posters and a stretchy Gum-Gum fist punting the Navy.

## Install

Copy the mod's Sigf.esp, Meshes, Textures and Scripts folders into Skyrim Special Edition's Data folder and enable Sigf.esp. Load a game: you get a straw hat and the Gum-Gum Pistol spell, and Wanted posters appear.
